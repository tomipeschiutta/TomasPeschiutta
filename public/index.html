01 — Perfil

Sobre mí

Soy Técnico Superior en Programación y desarrollador full-stack. Trabajo el ciclo completo de un producto: relevo el proceso real del negocio, modelo la base de datos, construyo la API y desarrollo la interfaz que usa el cliente.

La mayoría de lo que hice está en producción resolviendo procesos concretos: circuitos de aprobación de compras, trazabilidad ganadera y carga de pedidos integrada a un sistema de gestión. Me interesa que el software funcione offline, sincronice bien y no le complique la vida a quien lo usa.

  • Integración con sistemas de gestión existentes vía API REST
  • Arquitectura offline-first con sincronización a la nube
  • Autenticación y control de acceso por roles
  • Una sola base de código para web, móvil y escritorio
